# Security policy

Please **do not open a public issue** for a security problem in SKYHOST or in this CLI.

Report it privately:

- GitHub: **Security → Report a vulnerability** on this repository (private advisory), or
- email **syrixcompany@gmail.com** with the subject `SECURITY`.

Include what you found, how to reproduce it and the impact. We answer within 72 hours, keep you informed while
we fix it, and credit you if you wish once it is resolved.

Please only test against your own account and resources, never access other users' data, and do not run
denial-of-service or automated scanning against skyhost.tech.
